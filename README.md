# Innovate Africa Tech Initiative V1

**Presented by Light Brain**

A hands-on training program for building a complete IoT robot control system using ESP32-CAM and Arduino UNO. |

## Hardware

- ESP32-CAM (AI Thinker) + Arduino UNO R3
- 74HCT595N shift register + DC motors + motor driver
- HC-SR04 ultrasonic sensor
- USB webcam

## Software

- PlatformIO / Arduino IDE
- Python 3.8+ with MediaPipe, OpenCV

Each module folder contains its own README with wiring, build instructions, and usage details.
